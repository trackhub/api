# AI Agent System Instructions & Project Rules

## 1. Core Architecture Constraints
- **Do Not Edit Generated Files:** NEVER manually modify files inside `gorm/generated/` or `graph/generated/`. These files begin with the `// Code generated by` comment block.

## 2. Code Generation & Tooling Workflow
If you modify schema files or database models, you must automatically regenerate the corresponding boilerplate by running the exact terminal commands below:

| Target System | Source File / Directory | Generation Command |
| :--- | :--- | :--- |
| **GORM Models** | `gorm/model/` | `go tool gorm gen -i gorm/model/ -o gorm/generated` |
| **GraphQL API** | `schema.graphqls` | `go tool gqlgen` |

## 3. Step-by-Step Task Execution Protocol
Whenever the user asks you to add or modify a feature:
1. Locate the correct core definition file (`schema.graphqls` or `gorm/model/`).
2. Implement your structural changes *only* in those files.
3. **Execute the relevant generation command** via your terminal execution environment to rebuild the stubs.
4. Implement the concrete business logic within the non-generated resolver or application files.
5. Compile the application using `go build ./...` to verify type safety before finishing.
